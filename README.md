# 관상 (觀相) — 얼굴로 읽는 운명 공부

> 전통 관상학을 공부하고, 얼굴 특징으로 운세를 풀이해보는 프로젝트입니다.

## 이 저장소는

- **docs/** — 관상학 공부 노트 (삼정·오악, 십이궁, 부위별 풀이)
- **index.html** — 얼굴 특징을 고르면 관상 풀이를 생성해주는 웹앱 (브라우저에서 바로 실행)

## 관상학이란?

관상학(觀相學)은 얼굴의 생김새를 통해 그 사람의 성격, 건강, 운의 흐름을 읽어내는 동양 전통 학문입니다.
중국의 『마의상법(麻衣相法)』, 『유장상법(柳莊相法)』이 대표적인 고전이며, 조선시대에도 널리 연구되었습니다.

관상의 핵심 원리는 **"상(相)은 마음을 따라 변한다(相隨心生)"** 입니다.
타고난 얼굴보다 마음가짐과 표정이 쌓여 만들어진 얼굴을 더 중요하게 봅니다.

## 관상 풀이 웹앱

`index.html`을 브라우저로 열거나 [배포된 페이지](https://jhp3324-spec.github.io/gwansang/)에서 바로 사용할 수 있습니다.

- **면상(面相)** — 얼굴 8개 부위를 선택하면 초년·중년·말년·재물·애정운 풀이
- **성상(聲相)** — 목소리 유형 풀이 (『비본상인법』 성음편 반영)
- **지상(痣相)** — 점의 색·광택·위치 풀이 (흑여칠·면무선지 원칙 반영)
- **사주팔자** — 생년월일시 입력 시 년·월·일·시 4주 간지 자동 계산(입춘·절기 기준),
  일간(日干) 성격, 오행 분포 그래프, 관상×사주 종합 풀이까지 제공

## ⚠️ 유의사항

관상학은 과학적으로 검증된 학문이 아니라 **전통문화이자 재미로 보는 것**입니다.
풀이 결과로 사람을 판단하거나 중요한 결정을 내리는 데 사용하지 마세요.
관상 최고의 고전들도 결국 이렇게 말합니다 — **"관상보다 심상(心相)"**, 얼굴보다 마음이 운명을 만듭니다.
