# 부위별 풀이 — 이마·눈썹·눈·코·입·귀·턱

부위별 대표 유형과 전통 관상학의 풀이입니다.

## 이마 — 초년운·관운 (15~30세)

| 유형 | 풀이 |
|------|------|
| 넓고 둥근 이마 | 총명하고 부모덕·학운이 좋음. 일찍 두각을 나타냄 |
| 높이 솟은 이마 | 이상이 높고 관운(직장·명예)이 강함 |
| 좁은 이마 | 초년 고생·자수성가형. 경험으로 크는 상 |
| 흉터·주름 많은 이마 | 초년 굴곡. 단, 一자로 곧게 뻗은 주름 3개(천·인·지문)는 오히려 길상 |
| M자 이마(양끝 벗겨짐) | 학자·연구가형. 논리적이고 파고드는 기질 |

## 눈썹 — 형제운·성격 (31~34세)

| 유형 | 풀이 |
|------|------|
| 길고 가지런한 눈썹 | 정이 많고 형제·동료 덕이 있음 |
| 짙고 굵은 눈썹 | 의리·추진력이 강함. 다만 고집 주의 |
| 옅고 흐린 눈썹 | 담백하고 계산이 빠름. 인간관계는 넓고 얕게 |
| 일자 눈썹 | 강직하고 결단력 있음 |
| 초승달 눈썹 | 감성적이고 온화, 예술적 감각 |
| 눈썹 사이가 넓음(인당 넓음) | 낙천적이고 운이 트임 |
| 눈썹 사이가 좁음 | 생각이 많고 예민함 |

## 눈 — 마음의 창, 중년 초반 (35~40세)

관상에서 **얼굴의 절반은 눈**이라 할 만큼 중요합니다. 크기보다 **눈빛(안신眼神)** 이 핵심.

| 유형 | 풀이 |
|------|------|
| 흑백이 분명하고 빛나는 눈 | 총명하고 귀한 상. 어떤 얼굴이든 눈이 살면 산다 |
| 큰 눈 | 감수성 풍부, 표현력 좋음. 겁이 많은 편 |
| 가늘고 긴 눈 | 관찰력·인내심. 속을 잘 드러내지 않는 전략가형 |
| 눈꼬리가 올라간 눈 | 승부욕과 자존심이 강함 |
| 눈꼬리가 처진 눈 | 온화하고 인복 있음. 거절을 잘 못함 |
| 도톰한 애교살(와잠) | 정 많고 자녀운 좋음 |
| 눈 밑이 어두움 | 기력 저하, 요즘 운이 눌린 상태 |

## 코 — 재물운·자아, 중년 (41~50세)

| 유형 | 풀이 |
|------|------|
| 코끝이 둥글고 두툼(현담비) | 최고의 재물상. 돈이 모이고 심성이 후덕 |
| 콧방울이 탄탄함 | 모은 돈을 지킴. 금고가 튼튼한 상 |
| 높고 곧은 코 | 자존심·주관이 뚜렷. 리더형 |
| 낮은 코 | 협조적이고 유연함. 주관을 기르면 대성 |
| 매부리코 | 사업 수완·승부사 기질. 냉정하다는 평 주의 |
| 콧구멍이 훤히 보임 | 씀씀이가 큼. 들어와도 나가는 돈이 많음 |
| 코가 짧음 | 순발력·유머. 즉흥적 결정 주의 |

## 입 — 애정운·식복, 말년 입구 (51~60세)

| 유형 | 풀이 |
|------|------|
| 크고 윤곽이 뚜렷한 입 | 포부가 크고 식복·재복이 있음. 활동가형 |
| 작은 입 | 섬세하고 신중함. 소극적일 수 있음 |
| 입꼬리가 올라감 | 낙천적, 말년으로 갈수록 운이 핌 |
| 입꼬리가 처짐 | 비판적 안목. 불평이 잦으면 복이 샘 |
| 도톰한 입술 | 정이 깊고 애정운이 풍부 |
| 얇은 입술 | 이성적이고 말솜씨 좋음. 정 표현에 인색 |
| 입술 색이 밝은 홍색 | 건강하고 애정운이 열림 |

## 귀 — 유년운·수명·지혜 (1~14세)

| 유형 | 풀이 |
|------|------|
| 크고 두툼한 귀 | 복과 장수의 상. 어린 시절이 안정 |
| 귓불이 두툼(수주) | 부처님 귀. 재물·인덕이 따름 |
| 단단한 귀 | 신장이 튼튼, 의지가 강함 |
| 얇은 귀 | 감각이 예민하고 유행에 빠름 |
| 정면에서 안 보이는 귀(칩거이) | 부귀상. 신중하고 속이 깊음 |
| 정면에서 활짝 보이는 귀 | 개방적, 소식이 빠름. 귀가 얇다는 평 주의 |

## 턱 — 말년운·아랫사람운 (61세~)

| 유형 | 풀이 |
|------|------|
| 둥글고 두툼한 턱 | 말년이 풍요롭고 후배·부하 덕이 있음 |
| 각진 턱 | 의지·지구력이 강한 대기만성형 |
| 뾰족한 턱 | 감각적·예술적. 말년 대비 저축 필요 |
| 이중 턱 | 넉넉한 복. 베풀수록 커지는 상 |
| 주걱턱 | 정이 많고 말년에 오히려 강해지는 상 |
| 짧은 턱 | 순발력형. 진득함을 기르면 좋음 |

## 얼굴형 — 전체 기질

| 유형 | 풀이 |
|------|------|
| 둥근형(물형) | 원만하고 사교적. 장사·영업에 강함 |
| 각진형(금형) | 의지·실행력. 조직의 기둥 |
| 긴형(목형) | 사려깊은 학자형. 인정이 많음 |
| 역삼각형(화형) | 두뇌회전이 빠른 기획자형. 체력 관리 필요 |
| 계란형 | 균형잡힌 표준 길상. 다재다능 |

---

## 관상 볼 때의 대원칙

1. **부분보다 전체** — 좋은 코도 나쁜 균형 속에선 빛을 잃는다
2. **생김새보다 기색** — 같은 얼굴도 빛이 밝으면 운이 열린 것
3. **얼굴보다 표정** — 자주 짓는 표정이 얼굴을 만든다
4. **관상보다 심상(心相)** — 마의선사도 말년에 "상은 마음만 못하다" 하였다
