# 관상학 기초 — 삼정(三停)과 오악(五嶽)

## 1. 삼정(三停) — 얼굴을 세 구역으로 나누기

관상의 첫걸음은 얼굴을 위·중간·아래 세 구역으로 나누어 보는 것입니다.
각 구역은 인생의 시기를 나타냅니다.

| 구역 | 범위 | 담당 시기 | 보는 것 |
|------|------|-----------|---------|
| **상정(上停)** | 이마 머리선 ~ 눈썹 | 초년운 (15~30세) | 부모덕, 지능, 학운, 관운 |
| **중정(中停)** | 눈썹 ~ 코끝 | 중년운 (31~50세) | 의지력, 재물, 사회적 성취 |
| **하정(下停)** | 코끝 아래 ~ 턱 끝 | 말년운 (51세~) | 자손운, 부하운, 노년의 안정 |

**균형이 핵심**입니다. 삼정이 고르게 발달한 얼굴을 "삼정평등(三停平等)"이라 하여
평생 큰 굴곡 없이 순탄하게 사는 상으로 봅니다.

- 상정이 발달(넓고 시원한 이마) → 머리가 좋고 일찍 두각을 나타냄
- 중정이 발달(오똑한 코, 힘있는 광대) → 중년에 크게 일어섬
- 하정이 발달(두툼한 턱) → 말년이 풍요롭고 아랫사람 복이 있음

## 2. 오악(五嶽) — 얼굴의 다섯 산

얼굴의 도드라진 다섯 부위를 산에 비유합니다. 산은 솟아야 하되 서로 조화를 이뤄야 합니다.

| 오악 | 부위 | 상징 |
|------|------|------|
| 중악(中嶽) 숭산 | **코** | 자기 자신, 재물 |
| 남악(南嶽) 형산 | **이마** | 하늘, 윗사람, 관운 |
| 북악(北嶽) 항산 | **턱** | 땅, 아랫사람, 말년 |
| 동악(東嶽) 태산 | **왼쪽 광대** | 권세, 실행력 |
| 서악(西嶽) 화산 | **오른쪽 광대** | 권세, 인망 |

코(중악)가 아무리 좋아도 광대(동·서악)가 받쳐주지 않으면
"외로운 산봉우리(고봉)"라 하여 자기 고집만 세고 도와주는 사람이 없다고 봅니다.

## 3. 사독(四瀆) — 얼굴의 네 강

움푹 들어간 부위는 강(물길)에 비유합니다. 물길은 맑고 깊어야 합니다.

- **눈(하독)** — 맑고 흑백이 분명해야 총명
- **콧구멍(제독)** — 훤히 들여다보이지 않아야 재물이 새지 않음
- **입(회독)** — 크고 윤곽이 뚜렷해야 포부가 큼
- **귓구멍(강독)** — 깊어야 지혜가 깊음

## 4. 찰색(察色) — 얼굴빛 보기

같은 생김새라도 얼굴빛에 따라 운이 달라진다고 봅니다.

- **밝고 윤기 있는 홍황색(紅黃色)** — 운이 열리는 색
- **어둡고 그늘진 암색(暗色)** — 운이 막힌 색, 특히 이마·코끝의 어두운 기운을 꺼림
- 찰색은 매일 변하므로, 생김새(골격)는 평생운 / 찰색은 요즘운으로 구분해 봅니다

## 핵심 정리

> 관상은 한 부위만 보고 판단하지 않는다.
> **균형(삼정) → 조화(오악) → 맑음(사독) → 빛(찰색)** 순서로 전체를 본다.
