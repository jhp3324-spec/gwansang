# 십이궁(十二宮) — 얼굴에 있는 12개의 운명 자리

관상학은 얼굴을 12개의 "궁(宮)"으로 나누어, 각 자리에서 특정 운을 읽습니다.
『마의상법』의 핵심 체계입니다.

## 1. 명궁(命宮) — 인당, 운명의 중심

- **위치**: 양 눈썹 사이 (인당印堂)
- **보는 것**: 그 사람의 전체 운, 현재 운의 흐름
- 넓고(손가락 두 개 폭) 밝고 흠이 없으면 → 마음이 넓고 운이 잘 풀림
- 좁거나 주름·흉터가 있으면 → 생각이 많고 매사 막힘이 잦음
- 관상가들이 얼굴에서 **가장 먼저 보는 자리**

## 2. 재백궁(財帛宮) — 코, 재물 창고

- **위치**: 코 전체 (특히 코끝 준두準頭와 콧방울)
- 코끝이 둥글고 두툼 → 재물이 모임
- 콧방울(금갑金甲)이 힘있게 감싸줌 → 모은 재물을 지킴
- 콧구멍이 훤히 보임 → 씀씀이가 헤퍼 재물이 샘
- 코가 굽거나 마디짐 → 재물 기복이 큼

## 3. 형제궁(兄弟宮) — 눈썹

- **위치**: 양 눈썹
- 눈썹이 길고 가지런하며 윤기 → 형제·동료 덕이 있음
- 짧고 듬성듬성하거나 역모(거꾸로 난 털) → 형제 인연이 옅고 독립적

## 4. 전택궁(田宅宮) — 눈꺼풀, 부동산운

- **위치**: 눈썹과 눈 사이 (눈두덩)
- 넓고 도톰 → 물려받을 복, 집·땅 운이 좋음
- 좁거나 꺼짐 → 자수성가형, 조급함 주의

## 5. 남녀궁(男女宮) — 눈 밑, 자녀운

- **위치**: 눈 바로 아래 도톰한 곳 (와잠臥蠶, 애교살)
- 도톰하고 밝음 → 자녀 복, 정이 많음
- 꺼지고 어두움 → 자녀 걱정, 기력 저하

## 6. 노복궁(奴僕宮) — 턱, 아랫사람운

- **위치**: 턱 끝과 양옆 (지각地閣)
- 두툼하고 둥근 턱 → 부하·후배가 따르고 말년이 든든함
- 뾰족하고 빈약한 턱 → 말년 고독 주의, 아랫사람 덕 박함

## 7. 처첩궁(妻妾宮) — 눈꼬리 옆, 배우자운

- **위치**: 눈꼬리 옆 관자놀이 부근 (간문奸門)
- 판판하고 윤기 → 배우자 덕이 있고 가정이 화목
- 움푹 꺼지거나 잔주름·점 → 배우자와 갈등, 인연 변동

## 8. 질액궁(疾厄宮) — 콧대 뿌리, 건강운

- **위치**: 두 눈 사이 콧대 시작점 (산근山根)
- 높고 끊김 없음 → 건강 체질, 위기 극복력
- 낮거나 가로주름 → 잔병치레, 40대 초반 건강 고비 주의

## 9. 천이궁(遷移宮) — 이마 양 끝, 이동운

- **위치**: 이마 양쪽 가장자리 (역마驛馬)
- 밝고 깨끗 → 이사·여행·해외운이 좋고 나가서 성공
- 어둡거나 흠 → 이동수에 구설, 객지 고생

## 10. 관록궁(官祿宮) — 이마 중앙, 출세운

- **위치**: 이마 정중앙
- 솟은 듯 밝고 흠 없음 → 승진·시험·명예운이 강함
- 흉터·어두움 → 직장 변동이 잦고 관재 구설 주의

## 11. 복덕궁(福德宮) — 이마 양 위, 조상덕

- **위치**: 눈썹 꼬리 위 이마
- 둥글고 밝음 → 조상덕·인복이 있고 낙천적
- 꺼지고 어두움 → 복을 스스로 지어야 하는 상

## 12. 부모궁(父母宮) — 이마 좌우 위

- **위치**: 이마 좌우 상단 (일각日角·월각月角)
- 좌우가 균형있게 밝음 → 부모덕이 있고 유년이 안정
- 한쪽이 꺼지거나 어두움 → 부모 중 한 분과 인연이 옅음

---

## 실전 순서

1. **명궁(인당)** 부터 본다 — 전체 운의 문
2. 질문에 맞는 궁을 본다 — 돈 문제면 재백궁, 결혼이면 처첩궁
3. 궁의 생김새(평생운) + 찰색(요즘운)을 함께 본다
4. 반드시 삼정·오악의 균형 속에서 해석한다 — 한 궁만 보고 단정하지 않는다
