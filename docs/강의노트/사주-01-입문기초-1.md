# 사주명리학 입문기초강의 1 — 사주팔자의 구조와 네 기둥의 의미

> 출처: 한국역학교육센터 — https://www.youtube.com/watch?v=9xdvmBZ7iM0

> ※ 유튜브 자동 생성 자막의 오탈자가 매우 심해, 문맥으로 명리학 용어를 복원하여 재구성한 노트임.

## 핵심 요약

사주명리학의 첫걸음으로 '사주팔자(四柱八字)'라는 말의 뜻을 풀어 설명하는 강의다. 태어난 연·월·일·시를 네 개의 기둥(四柱)으로 세우고, 각 기둥이 천간(天干)과 지지(地支) 두 글자로 이루어져 모두 여덟 글자(八字)가 된다는 기본 구조를 배운다. 실제 강의 당일(2020년 7월 11일, 경자년 계미월 병신일)의 사주를 만세력으로 뽑아 보이며, 연주=조상·초년, 월주=부모형제·청년, 일주=나와 배우자·장년, 시주=자식·말년이라는 각 기둥(궁위)의 의미를 설명한다. 공부 준비물로 만세력 앱(원광만세력) 설치와 세로쓰기(우→좌) 기록법도 안내한다.

## 강의 내용 정리

### 1. 사주(四柱)와 팔자(八字)의 뜻

- **사주四柱** = "네 개의 기둥". 사람이 태어난 **연(年)·월(月)·일(日)·시(時)**를 각각 하나의 기둥으로 세운 것.
  - 연주(年柱), 월주(月柱), 일주(日柱), 시주(時柱)의 네 기둥.
- 각 기둥은 위에 **천간(天干)** 한 글자, 아래에 **지지(地支)** 한 글자, 총 두 글자로 구성된다.
- 기둥이 4개 × 글자 2개 = **여덟 글자**, 그래서 **팔자(八字)**라 한다. 합쳐서 **사주팔자(四柱八字)**.
- 이 여덟 글자 안에 그 사람의 **개별적인 성정(性情)·운명 정보**가 담겨 있다고 보는 것이 명리학의 출발점이다.
- "팔자가 좋다/사납다", "아이고 내 팔자야" 같은 일상 표현이 모두 여기서 나온 말이다. 강사는 "이런 공부를 스스로 찾아서 할 수 있다는 것 자체가 이미 팔자가 나쁘지 않은 것"이라고 덧붙인다.

### 2. 천간(天干)과 지지(地支)

- 기둥의 **위 글자 = 하늘(天)의 줄기(干) → 천간**. 하늘은 상위 개념이므로 '줄기(干)'를 쓴다.
- 기둥의 **아래 글자 = 땅(地)의 가지(支) → 지지**. 땅은 하위 개념이므로 '가지(支)'를 쓴다.
- 천간과 지지를 줄여서 **간지(干支)**라고 부른다.
- 천간은 **10개**(십천간), 지지는 **12개**(십이지지)이다. 구체적인 글자는 다음 강의에서 다룬다.
- 태어난 '날'의 간지를 **일주(日柱)**라 하고, 그중 천간을 **일간(日干)**이라 하는데, 일간이 곧 '나 자신'을 나타낸다. 예: "저는 병신(丙申)일에 태어난 병화(丙火) 일간입니다"처럼 말할 수 있어야 한다.

### 3. 실습 — 강의 당일의 사주 뽑기

강의 촬영일: **2020년 7월 11일 저녁 8시 15분(술시)** 기준.

| 구분 | 시주 | 일주 | 월주 | 연주 |
|---|---|---|---|---|
| 천간 | 무(戊) | 병(丙) | 계(癸) | 경(庚) |
| 지지 | 술(戌) | 신(申) | 미(未) | 자(子) |

- 2020년 = **경자년(庚子年)**, 7월(소서 이후) = **계미월(癸未月)**, 이날 = **병신일(丙申日)**, 저녁 8시 15분 = **무술시(戊戌時)**.
- 이렇게 만세력에서 네 기둥을 뽑는 것을 "사주를 세운다"고 한다.
- 사주를 뽑으려면 반드시 **생년·월·일·시**와 **성별(남명男命/여명女命)**을 함께 기록해야 한다. 남자 사주는 건명(乾命), 여자 사주는 곤명(坤命)이라 한다.

### 4. 사주 기록법 — 세로쓰기, 오른쪽에서 왼쪽으로

- 사주는 **세로쓰기**로, **오른쪽에서 왼쪽으로** 연→월→일→시 순서로 적는 것이 전통이다.
- 이유: 종이가 없던 고대에 **죽간(竹簡)** — 대나무를 쪼개 만든 조각 — 에 글을 썼기 때문. 대나무 조각은 세로로 길어 세로쓰기가 자연스러웠고, 조각들을 끈으로 엮어 말아둔 것이 '책(冊)'이라는 글자의 유래다(책을 세는 단위 '권卷'도 '말다'에서 나옴).
- 그래서 사주 명식도 관례상 세로·우측 기준으로 배열한다.

### 5. 네 기둥(궁위)의 의미 — 근묘화실

각 기둥은 시간의 흐름과 육친(六親) 관계를 함께 나타낸다.

| 기둥 | 시기 | 육친(가족) 의미 |
|---|---|---|
| 연주(年柱) | 초년 | 조상 — 나의 혈통·뿌리 |
| 월주(月柱) | 청년 | 부모·형제, 직장(사회) 자리 |
| 일주(日柱) | 장년 | **나 자신(일간)** 과 **배우자(일지)** |
| 시주(時柱) | 말년 | 자식 |

- **일주가 가장 중요하다.** 내가 없으면 세상을 인식할 주체가 없기 때문에, 여덟 글자의 중심(주인공)은 일간이다.
- **일지(日支)** — 내가 깔고 앉은 자리 — 는 **배우자궁**이다. 배우자와 더불어 '내가 사는 집·가정'의 개념도 함께 본다.
  - 여자 사주라면 일지가 남편 자리, 남자 사주라면 아내 자리가 된다.
- 위(천간)는 하늘·드러난 것, 아래(지지)는 땅·현실이라는 대응도 함께 기억한다.

### 6. 공부 준비물 — 만세력

- 사주를 뽑으려면 **만세력(萬歲曆)** 이 필요하다. 요즘은 앱으로 대신한다.
- 강사 추천: **원광만세력** 앱(안드로이드·아이폰 모두 무료). 원광디지털대학교에서 만든 것으로 무료지만 잘 만들어져 있다.
- 앱에서 생년월일시·성별·양력/음력을 입력하면 사주 명식(간지·대운 등)이 자동으로 나온다.
- 다만 앱에 의존하기 전에 **간지 글자를 직접 읽고 쓸 줄 알아야** 공부가 된다는 점을 강조.

## 용어 정리

| 용어 | 한자 | 뜻 |
|---|---|---|
| 사주 | 四柱 | 태어난 연·월·일·시로 세운 네 개의 기둥 |
| 팔자 | 八字 | 네 기둥을 이루는 여덟 글자 |
| 천간 | 天干 | 기둥의 위 글자. 하늘의 줄기, 모두 10개 |
| 지지 | 地支 | 기둥의 아래 글자. 땅의 가지, 모두 12개 |
| 간지 | 干支 | 천간과 지지를 합쳐 부르는 말 |
| 연주 | 年柱 | 태어난 해의 기둥. 조상·초년 |
| 월주 | 月柱 | 태어난 달의 기둥. 부모형제·청년 |
| 일주 | 日柱 | 태어난 날의 기둥. 나와 배우자·장년 |
| 시주 | 時柱 | 태어난 시각의 기둥. 자식·말년 |
| 일간 | 日干 | 일주의 천간. 사주의 주인공인 '나' |
| 일지 | 日支 | 일주의 지지. 배우자궁·가정 |
| 명리학 | 命理學 | 목숨 명, 이치 리 — 타고난 명의 이치를 연구하는 학문 |
| 건명 | 乾命 | 남자의 사주 |
| 곤명 | 坤命 | 여자의 사주 |
| 만세력 | 萬歲曆 | 연·월·일·시의 간지를 찾는 달력(책 또는 앱) |
| 죽간 | 竹簡 | 종이 이전에 쓰던 대나무 조각 기록물. 세로쓰기 관습의 유래 |
