# 적천수천미 p.101 — 방국(方局)장 강독 (2) : 예시 명조

> 출처: 한국역학교육센터 — https://www.youtube.com/watch?v=hzNojRZ0cZg

> ※ 이 영상은 자동 생성 자막 상태가 특히 좋지 않아 개요 위주로 정리함. 예시 명조의 여덟 글자 전체와 일부 운·연도의 간지는 자막만으로 확정하기 어려워, 문맥으로 복원 가능한 범위까지만 적는다.

## 핵심 요약

앞 시간의 방국(方局) 이론에 이어 p.101의 예시 명조를 실전 강독하는 시간이다. 겨울 축월(丑月)에 태어난 병화(丙火) 일간이 천간의 임수(壬水)·계수(癸水) 관살과 재성 신금(辛金)에 눌려 심하게 신약해진 명조로, 억부로 보나 조후로 보나 목(인수)·화(비겁)가 절실하며 그중에서도 수 기운을 받아 화로 돌려주는 인수 목이 으뜸 용신이 된다. 초년 목화운에는 좋은 교육을 받고 일찍 벼슬에 올라 넉넉하게 살았으나, 운이 금수로 바뀌자 관살은 더 왕해지고 인수는 극을 받아 몰락하고 끝내 죽음을 만났다. 말미에는 충(沖)과 왕지(旺支)·회국(會局)의 관계 — 왕지는 뿌리가 깊고 국의 도움을 받아 쉽게 충으로 무너지지 않는다 — 에 대한 질의응답이 이어진다.

## 강의 내용 정리

### 1. 예시 명조의 구조 — 엄동의 병화, 재관에 눌린 신약

- **병화(丙火) 일간이 신축월(辛丑月), 한겨울에 태어났다.** 천간에 임수·계수 **관살이 투출**하여 혼잡하고, 월간의 재성 신금이 관살을 생하니(재생살), 재와 관 때문에 일간의 힘이 크게 꺾인 **신약** 명조다.
- 겨울의 화 일간이므로 **조후(調候)로도 목·화가 절실**하다. 억부와 조후가 같은 방향을 가리키는 전형이다.
- **용신의 우선순위**: 인수(목)와 비겁(화)이 모두 필요하지만, **인수 목이 훨씬 더 중요**하다. 목은 왕한 수 기운을 받아내어 화로 돌려주는 **통관(살인상생)**의 역할과, 언 사주를 데우는 조후의 역할을 겸하기 때문이다.
- **축토(丑土)의 성질**: 축은 습토(濕土)이자 언 흙(동토)이다. 물을 저장할 수는 있으나 얼어 있어 일주를 돕기는커녕 오히려 화기를 설하여 어둡게 한다(회화晦火). 언 흙이 제 구실을 하려면 반드시 화가 있어야 한다.

### 2. 운의 흐름과 실제 인생

- **초년 목·화운**: 어려서부터 **좋은 교육 기회**를 누렸고 학문에 남음이 있었으며, **일찍 벼슬길에 올라** 풍족하고 여유 있게 살았다. 용신(목화)운이 초년에 오면 부모덕·학업·조기 등과로 나타나는 통변이다.
- **금·수운 전환 후**: 운이 바뀌어 금수가 오자 재는 관살을 돕고 관살은 인수·일간을 치니, 일주를 돕지 못할 뿐 아니라 오히려 해친다. 이 사주는 왕한 관살을 눌러 줄 힘이 원국에 없으므로, 관살을 더 키우는 운에서 **벼슬이 꺾이고 가산이 무너지는 몰락**을 겪었고, 마침내 **죽음을 만났다**.
- 강사는 임상 관점을 덧붙였다: 사람이 죽음에 이를 때는 원국의 병(病)을 키우는 운이 겹겹이 들어올 때이며, 이 명조처럼 신약한데 재관이 태왕한 사주는 인수·비겁 운에 발하고 재관을 돕는 운에 무너진다는 것이 통변의 골자다.

### 3. 질의응답 — 충(沖)과 왕지·회국, 사망 시점

- 학생 질문: "특정 운에서 충이 겹치면 이때 죽었을 수도 있지 않은가?" — 강사는 그 가능성을 인정하면서 충의 성패를 가르는 원칙을 설명했다.
- **왕지(子午卯酉)는 쉽게 충으로 무너지지 않는다.** 왕지는 그 오행의 기가 가장 순수하고 뿌리가 깊은 자리이며, 주변 지지가 **회국(합국)을 이루어 왕지를 도우면** 충이 와도 잘 깨지지 않는다. 예컨대 해묘(亥卯)가 목국을 이루고 있으면 묘를 충해도 쉽게 뽑히지 않는다.
- 반대로 임자(壬子)·계축(癸丑)처럼 수 기운이 겹겹인 한랭한 구조에서 병화는 몹시 약하므로, 약한 글자를 충·극하는 운이 겹치면 생명까지 위태로울 수 있다.
- 이 문답은 앞 강의(방국 이론)와 이어진다 — **지지의 방·국 세력이 충의 성패와 왕쇠 판단을 좌우한다**는 것이 이 장을 예시 명조로 확인하는 핵심이다.
- 초년이 좋고 말년이 나쁜 이 명조를 두고 "초장 끝발이 좋았다"는 말로, 운의 순서가 인생의 모양을 결정함을 강조하며 마무리했다.

## 용어 정리

| 용어 | 한자 | 뜻 |
|---|---|---|
| 조후 | 調候 | 사주의 한난조습(寒暖燥濕)을 조절하는 용신법 |
| 억부 | 抑扶 | 강한 것은 누르고 약한 것은 돕는 용신법 |
| 신약 | 身弱 | 일간의 힘이 약함 |
| 투출 | 透出 | 지지에 감춰진 오행이 천간에 드러남 |
| 관살혼잡 | 官殺混雜 | 정관과 편관(칠살)이 함께 섞여 나타남 |
| 재생살 | 財生殺 | 재성이 관살을 생하여 일간을 치는 힘을 키움 |
| 살인상생 | 殺印相生 | 관살의 기운을 인수가 받아 일간에게 돌려 통관시킴 |
| 통관 | 通關 | 맞서는 두 세력 사이를 다른 오행이 이어 줌 |
| 인수 | 印綬 | 일간을 생해 주는 십신 |
| 비겁 | 比劫 | 비견과 겁재. 일간과 같은 오행 |
| 습토 | 濕土 | 물기를 머금은 토(丑·辰). 화기를 설함 |
| 회화 | 晦火 | 습토가 화기를 어둡게 하고 빛을 잃게 함 |
| 충 | 沖 | 지지가 정면으로 부딪쳐 다투는 작용 |
| 왕지 | 旺支 | 자오묘유(子午卯酉). 오행의 기가 가장 왕성한 자리 |
| 회국 | 會局 | 지지가 모여 하나의 오행 국을 이룸(삼합국 등) |
| 등과 | 登科 | 과거에 급제함. 벼슬길에 오름 |
| 용신/희신 | 用神/喜神 | 사주를 살리는 핵심 글자 / 용신을 돕는 글자 |
| 기신 | 忌神 | 사주에 해로운 글자 |
